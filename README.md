A calm-dip scalper for the pump.fun Sharpe sprint: it buys a bounded dip only while the tape is calm and buyers are returning, takes small quick profits, cuts losers fast, and never pyramids — steady small wins for hourly Sharpe, not one lucky moonshot.

## Run it

The grader runs `node main.ts` on the replay harness. `strategy.ts` holds the strategy; `vendor/makefun-bot.ts` is the kit's vendored shim (not our code).

```sh
node main.ts
```
